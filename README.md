## Overview

Static personal portfolio website deployed to GitHub Pages. Built with plain HTML, CSS/SCSS, and vanilla JavaScript — no build tools or package managers required.

**Live:** [https://www.developerks.website](https://www.developerks.website)

## Pages

| File | Description |
|------|-------------|
| `index.html` | Landing/hero page with navigation toolbar, contact info, and image gallery |
| `portfolio.html` | Skills and work portfolio detail page |
| `links.html` | Curated developer resource links organized by category |

## Local Development

```bash
# Python
python3 -m http.server 8080

# or Node.js
npx serve .
```

Open `http://localhost:8080` in a browser, or open the HTML files directly from the filesystem.

## Deployment

Pushing to `main` automatically deploys the site via GitHub Actions to GitHub Pages.

## Stack

- HTML5, CSS3 (SCSS source compiled to CSS)
- Vanilla JavaScript
- Font Awesome 5 (icons)
- Google Fonts – Poppins
- FsLightbox (vendored, image gallery)
- Google Analytics / Google Tag Manager
- Cookiebot (consent management)
